# Logging Codebase Auditor

An AI agent skill to audit logging quality, security, observability coverage, duplication, excessive volume, and storage-capacity risks in application codebases.

## Installation

```bash
# Add from my-skills collection (Recommended)
npx skills add HaoNgo232/my-skills --skill logging-codebase-auditor

# Or install standalone
npx skills add HaoNgo232/logging-codebase-auditor

# Or install globally
npx skills add HaoNgo232/my-skills --skill logging-codebase-auditor -g
```

## Usage

Ask your AI assistant:

```text
Audit the logging practices in this codebase.
```
