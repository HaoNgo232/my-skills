# 🎼 Orchestrator Skill

> Coordinates multi-agent workflows for complex programming, architecture, and engineering tasks. Decomposes large goals into dependency graphs, spawns and supervises specialized subagents, enforces interface contracts, manages quality gates, and synthesizes final deliverables.

---

## ⚡ Quick Install

Install this skill directly into your current workspace using `npx skills`:

```bash
npx skills add HaoNgo232/my-skills --skill orchestrator
```

---

## 🎯 What this Skill Does

- **Task Decomposition & DAG Mapping**: Breaks complex multi-file features and architecture overhauls into a Directed Acyclic Graph (DAG) of parallel and sequential subtasks.
- **Tiered Model Delegation**: Uses fast `flash` models for high-volume research and symbol lookups; reserves `pro` / `inherit` models for deep coding, architecture, and security auditing.
- **Reactive Supervision (No-polling)**: Coordinates subagents efficiently using native event-driven message wakeups without waste.
- **Multi-Axis Quality Gate**: Ensures automated tests pass, interfaces match, and adversarial code reviews are clean before presenting changes.
- **User Confirmation Gate**: Always provides a read-only proposal and diff for user approval before making destructive edits or commits.
